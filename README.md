# Dealers Diary

Stock, bills, retailers and companies for a dealer or distributor, on an Android phone. Works without internet. Your data stays encrypted on the phone, with daily backups.

## Download

**[Download the latest Dealers Diary (Android APK)](https://github.com/uditgaurav/DealersDiary/releases/latest/download/DealersDiary.apk)**

All versions are listed under [Releases](https://github.com/uditgaurav/DealersDiary/releases).

## Install

1. Open the download link on your Android phone.
2. When the download finishes, open the file.
3. If Android asks, allow your browser to "install unknown apps", then tap **Install**.

To update, download the newest version and install it over the old one. Your data stays.

This repository only hosts the app for download.
